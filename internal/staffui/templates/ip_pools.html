IP pools

The address ranges this network owns. A static pool is what addresses are handed out from here — a subscriber given one gets it as Framed-IP-Address on every authentication, so the router stops choosing for them. Record the router's own DHCP and CGNAT ranges too: nothing is allocated from those, but having them written down is what answers "where did this address come from" when one collides. Exclude the network, gateway and broadcast addresses before handing any out. Addresses are assigned to a subscriber from their own page.
