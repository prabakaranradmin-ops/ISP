Paying at any stage restores service on the next pass. Changes apply within the hour. Anyone online when they enter or leave a suspension is reconnected, so the change reaches the session they already have.

How soft suspension is enforced

A soft-suspended subscriber's MikroTik session is put on the address list {{$d.GardenList}}. The router restricts that list only once deploy/mikrotik/walled-garden.rsc has been run on it. On a router without those rules, soft suspension restricts nothing.

On a NAS that is not MikroTik there is no walled garden, so a soft-suspended subscriber is refused, the same as at hard suspension, and counted in radius_walled_garden_refused_total.
