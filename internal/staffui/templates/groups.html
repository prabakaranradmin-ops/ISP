Subscriber groups

A group is a name you give a set of your own customers — a locality, an apartment block, a promotion cohort, the twenty on one feeder cable. Subscribers could already be filtered by plan, status and franchise, which are facts the system holds about them; a group is a set you define.

A subscriber can be in several groups at once: somebody is in "Anna Nagar" and also in "Corporate", and those are not alternatives. Groups filter the subscriber directory, address an announcement, and scope the subscribers report.

Add a group

Two live groups cannot share a name, because a group is referred to by name in conversation. A retired one may share a name with its replacement, which is how a group gets rebuilt after a survey.

Member counts

A group's count excludes terminated subscribers, so it is the reach a message to the group would actually have. The directory filter, the announcement fan-out and the subscribers report all count the same way — if they differed, whichever an operator checked first would make the other two look broken.
