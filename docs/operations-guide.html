Using the operations console

Every screen a member of staff can reach, in the order you'd actually meet them: sign in, find a customer, manage tariffs and money, manage the network, and see what a customer sees themselves.

02Changing your password

Change password sits in the top-right corner on every screen, for every role. You'll need your current password to set a new one.

03Staff accounts Owner only

Create logins for the rest of your team, and manage the ones that already exist.

  1. Fill in Add a staff account at the bottom — username, full name, a password of at least 10 characters, and a role.
  2. To change someone later, open Edit on their row: switch their role, toggle LEA access, tick or untick Active, or set a new password — leave the password field blank to leave it alone.
!

The console won't let you deactivate or demote the last active owner account — that would lock everyone out of this very screen with no way back in short of editing the database directly.

04Subscribers

The list every role starts from — search by username or ID, open a record, or act on several at once.

Bulk actions (owner and billing admin only) — tick the customers you want, choose one action, and only the fields that action needs matter:

ActionWhat happens
Change planMoves every selected customer to the chosen plan immediately.
Suspend / resumeSets every selected customer's status directly.
Wallet creditFiles one pending approval per customer — a second staff member still has to approve each before any money actually moves. Bulk never skips that check.
Send notificationSends your message to exactly the customers you ticked, by whichever channels (SMS/Email/WhatsApp/portal banner) you check.

05A subscriber's page

Click Open on any row. What you see is organized into tabs, and which tabs appear depends on your role.

Speed override, owner-only, is a temporary rate change that leaves the customer's billed plan untouched — for a support gesture ("give them 100 Mbps for the rest of the day") without editing what they're paying for. Set a duration and it reverts on its own; clear it manually any time.

06Adding a subscriber

  1. Click New subscriber from the Subscribers list.
  2. Fill in the CAF number, username, mobile number and a plan — a plan has to exist first (see Catalogue).
  3. Enter the state exactly as registered on their KYC — this is what decides whether they're billed CGST+SGST or IGST later.
  4. Set a password for them, and Aadhaar/PAN if you're collecting it now. Submitting takes you straight to their new record.

07Plans & GST rates

Nothing can be billed until at least one plan and one GST rate exist — this is usually the very first screen a new install needs.

Speed is entered MikroTik-style, upload/download, e.g. 100M/100M. A fair-use threshold is optional — leave it blank for unlimited, or set it with a throttle speed that kicks in once a customer crosses it.

08Billing & the GSTR-1 export

The GSTR-1 export card downloads a CSV for your accountant — B2B invoices individually, B2C aggregated by state and rate, plus the HSN summary. Leave the period blank for last month (a return is filed for a period that's actually finished). This is an accountant-ready file, not the GST portal's own upload format.

09Revenue Owner only

The collections panel shows how much is outstanding at each stage of the dunning ladder (grace period → soft suspension → hard suspension) and how much has actually been recovered month over month.

10Routers

Register the hardware that authenticates your customers — MikroTik, Cisco, Huawei, ZTE, Juniper, or a wireless controller.

  1. Fill in the router's own IP address, and a description if you like.
  2. Click Generate secret instead of typing one — it fills the field with a strong random value and reveals the exact commands to run on the router itself, using the identical secret.
  3. Fill in this server's address, as the router will reach it — its real network address, not the one the console happens to be open at.
  4. Copy the commands into a Winbox or SSH terminal on the router, then click Register device here.
i

Ready-made commands are shown for MikroTik. Other vendors get the same generated secret plus the plain connection details to configure by hand.

12Demo data Owner only

Populate a fresh install with presentable sample data for a client walkthrough — no SQL, no command line.

Click Remove demo data any time to take it all back out again — it only ever removes what this screen added.

13Keyboard shortcuts

Press ? anywhere in the console for a cheat-sheet. The short version:

KeysDoes what
/Jumps the cursor into the nearest search box

Every shortcut is a convenience layer on top of ordinary links and forms — the console works exactly the same with JavaScript turned off.
